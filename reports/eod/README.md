# reports/eod/ — end-of-day reports (OFFICE.md §19)

Evidence only. One file per day: `YYYY-MM-DD.md`, six sections as in OFFICE.md §19.

- No placeholder rows, no sample numbers, no "approximately", no "~".
- Every number is measured and names its source (file path, command output, or commit id).
- Unknown values are written as "not measured". If nothing shipped, section 1 says "nothing shipped".
