# TASK-015 — 10th Science: Last-Minute Notes, Units 1–3 (night-before card)

Lane: ONEWORD/QBANK (agent-03)

Blocked by: TASK-013
Owner needed: no
Estimate: 1–2 agent sessions

## Why this task
The night before the exam is when a student decides whether our app is worth opening. A 1–2 page card per unit, printable at A5, is the highest-perceived-value thing we can hand over — and it costs almost nothing once Complete/Topper notes exist, because it is a **compression, not new content**.

## Inputs
| What | Where | State |
|---|---|---|
| Topper Notes Unit 1 | `StudyHub/TN/10th/Science/Notes/10_Science_TopperNotes_Unit01_A5.pdf` | from TASK-013 |
| Q-bank ch1 | `StudyHub/TN/10th/Science/QBank/` | from TASK-010 |

## Steps
1. For each unit (1–3): one A5 front page = formulae + one-line definitions + diagram-label lists + units; one A5 back page = "if asked X, write Y" patterns for the 5 most likely questions + top 10 traps.
2. Bullets and boxes only — no paragraphs, no full sentences where a fragment works.
3. **Introduce nothing new.** Every line must already exist in the Complete/Topper notes for that unit. This is a compression.
4. Print check: at A5 with no wasted margin, every line legible without zooming.
5. Output: `10_Science_LastMinute_Unit01-03_A5.pdf` → `StudyHub/TN/10th/Science/Notes/`.
6. Count check: every formula and definition in the card must be traceable to the source note (list the mapping in `log.md` — a one-line audit trail).
