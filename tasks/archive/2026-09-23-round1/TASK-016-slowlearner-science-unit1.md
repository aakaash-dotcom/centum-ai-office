## Steps
1. Restructure Unit 1 into the slow-learner shape: one idea per page-panel, the textbook's language simplified, every technical term defined at first use, an example before the theory where possible.
2. Add "check yourself" micro-questions after each panel (3 per unit) with answers directly below (this audience needs immediate feedback).
3. Add a pronunciation/vocabulary panel for the Tamil-medium student: English technical term → Tamil meaning → one usage example.
4. Diagrams: same labelled diagrams as the Topper notes, but larger, with label callouts drawn around the figure — **labels verified twice against the textbook** (the shipped wrong-label error class must not repeat).
5. No paragraphs longer than 3 lines. No page more than 40% text.
6. Output: `10_Science_SlowLearner_Unit01_A5.pdf` → `StudyHub/TN/10th/Science/SlowLearners/`.
7. Write the source-provenance line into the log: "all content written in-house from the TN textbook, no third-party SLM used". This is a compliance record, not a formality.
