## Why this task
Maths Topper Notes live or die on **worked method**, not prose. A student must be able to copy the exact step sequence and get full marks. This is also the safest high-value note type to check for correctness (the arithmetic either works or it does not).

## Steps
1. Per chapter: the formulae/method sheet (every formula used in the chapter, with the condition under which it applies).
2. For each major problem type: the step template a student writes in the exam ("Step 1: write the relation. Step 2: substitute. Step 3: simplify. Step 4: state the answer with unit.").
3. 3 fully worked model problems per chapter with the mark split shown against each step.
4. A traps list: sign errors, unit omissions, rounding, formula misapplication — each with a one-line fix.
5. A "what changes if the question is twisted" box: the 2–3 common variants of each problem type.
6. Output: `10_Maths_TopperNotes_Ch01-03_A5.pdf` → `StudyHub/TN/10th/Maths/Notes/`.
7. **Verify every worked number.** Re-solve each problem independently before publishing; a wrong step in Maths Topper Notes is a product-killing defect.
